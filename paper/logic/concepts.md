## Concept 1: Cognitive Fire Defense Pipeline
- Notation: CFDP
- Definition: An asymmetric Edge-Cloud hybrid architecture.
- Boundary conditions: Cloud node must have >16GB VRAM.
- Related concepts: Edge Computing

## Concept 2: Sentinel Node
- Notation: S
- Definition: Lightweight edge model (YOLO11n).
- Boundary conditions: Real-time inference.
- Related concepts: CFDP

## Concept 3: Commander Node
- Notation: C
- Definition: Zero-shot semantic pipeline (OWLv2).
- Boundary conditions: Cloud-hosted.
- Related concepts: CFDP

## Concept 4: Visual Mimic
- Notation: VM
- Definition: Non-fire artifacts resembling fire/smoke (sunsets, fog).
- Boundary conditions: Distance > 1km.
- Related concepts: False Positives

## Concept 5: Mixed Precision Training
- Notation: FP16
- Definition: Halves memory usage during training.
- Boundary conditions: Hardware must support FP16.
- Related concepts: T4 GPU
