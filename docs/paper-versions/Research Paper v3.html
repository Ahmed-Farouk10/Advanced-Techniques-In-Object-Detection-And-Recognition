Project Proposal: Advanced Edge-Optimized Forest Fire Object Detection (v3)

Team: Esraa Nasr and Ahmed Ayman

Selection of Application Category: Forest Fire & Environmental Disaster Management

Review: Current Challenges and Research Trends

Traditional forest fire detection models focus purely on drawing bounding boxes around smoke or flames. This approach suffers from two major bottlenecks: heavy models cannot run on cheap drones, and fast edge models trigger too many false alarms (confusing clouds, fog, or sunset glare for fire). Furthermore, high-resolution 4K imagery from watchtowers is often naively resized, obliterating the very pixels that indicate early-stage distant smoke.

The Novel Discovery Angle: This project proposes a "Cognitive Fire Defense Pipeline"—a 100% Edge-native architecture tailored for real-world compute limits (e.g., T4 GPUs or Jetson Nano). We conduct three rigorous experiments across two data distributions to prove that lightweight edge models (like YOLO11n or RT-DETR) acting as the Sentinel can be effectively paired with a zero-shot, prompt-driven YOLO-World model acting as the Commander. We also benchmark these against heavy SOTA transformers like Co-DETR to prove our edge-native pipeline achieves comparable accuracy without the massive compute footprint.

Selection of Object Detection Models

To derive new insights, we selected six state-of-the-art (SOTA) models representing fundamentally different architectural philosophies, heavily focusing on the clash between modern CNNs and the latest Vision Transformers (DETRs).

Experiment 1: The Micro View (FLAME Dataset - Drone/UAV Imagery)

Environment: Dynamic, moving cameras, top-down angles, requiring high processing speed on low-power edge devices.

Goal: Discover if the first real-time Vision Transformer (RT-DETR) can outperform the best modern CNN (YOLO11n) for dynamic edge deployment.

  1. The Modern CNN Edge Standard: YOLO11n (Nano)
    • Architecture Family: One-Stage CNN Detector.
    • Why it’s in the stack: Designed specifically for extreme edge devices. It tests the absolute baseline of speed and memory efficiency against motion blur.
  1. The Real-Time Transformer: RT-DETR
    • Architecture Family: Real-Time DEtection TRansformer.
    • Why it’s in the stack: RT-DETR is the first transformer to break the real-time speed barrier. It allows us to directly test if the global attention mechanisms of Transformers can beat the local convolutions of YOLO on a drone's strict hardware budget.
  1. The Two-Stage Lightweight: Faster R-CNN (MobileNetV3)
    • Architecture Family: Two-Stage Detector.
    • Why it’s in the stack: Retains the stable Region Proposal Network (RPN) to test if explicit two-stage localization handles complex forest backgrounds better than one-stage models.

Experiment 2: The Macro View (D-Fire Dataset - Watchtower/Panoramic)

Environment: Static cameras, extreme distances, heavy environmental noise (clouds, haze, sunsets).

Goal: Determine whether the zero-shot Open Vocabulary semantics of YOLO-World can eliminate false positives as effectively as the massive, heavy, state-of-the-art Collaborative DETR (Co-DETR).

  1. The Heavy SOTA Baseline: Co-DETR (Collaborative DETR)
    • Architecture Family: Collaborative Vision Transformer.
    • Why it’s in the stack: Co-DETR represents the absolute pinnacle of object detection accuracy by collaboratively training multiple parallel auxiliary heads. It serves as our "God Model" baseline—representing the maximum achievable accuracy when compute limits are ignored.
  1. The Zero-Shot Edge Commander: YOLO-World
    • Architecture Family: Open-Vocabulary Object Detector (Prompt-then-Detect).
    • Why it’s in the stack: YOLO-World uses a Re-parameterizable Vision-Language Path Aggregation Network (RepVL-PAN) to fuse pre-computed text embeddings ("smoke", "sunset") directly into the weights. We test if this zero-shot semantic filtering can match Co-DETR's accuracy while remaining fast enough to run on the edge.
  1. The Legacy Transformer: Swin-T (Tiny)
    • Why it’s in the stack: Used as a benchmark to compare traditional hierarchical windowing transformers against the modern DETR (Co-DETR and RT-DETR) architectures.

Experiment 3: Slicing Aided Hyper Inference (SAHI) Ablation

Goal: Prove that naive resizing of 4K watchtower imagery destroys tiny object detection performance.

Procedure: We will compare the recall of our models using standard 512x512 downscaling against deployment with SAHI, which slices the high-resolution image into overlapping patches, runs inference on each patch, and merges the bounding boxes.

Environment Setup

The Development and Training Environment:

  • Hardware: NVIDIA T4 (Simulating Edge constraints).
  • Frameworks: PyTorch, Ultralytics (YOLO11n, YOLO-World, RT-DETR), Detectron2 (Faster R-CNN), MMDetection (Co-DETR).
  • Inference Optimization: TensorRT / ONNX for final edge benchmarking.

Dataset Preprocessing & Rigor

Forest fire data presents unique challenges that require strict preprocessing:

  • Target Datasets: FLAME Dataset (Drone imagery, moving background), D-Fire Dataset (Static, long-distance imagery).
    • Classes: 2 (Fire, Smoke).
    • Class Imbalance Mitigation: We will strictly employ Focal Loss during training to dynamically scale cross-entropy based on prediction confidence, forcing the model to focus on hard, tiny smoke patches instead of the massive background. Furthermore, Mosaic Augmentation will be used to simulate scale variation.
    • Small Object Detection: Preserving scale via SAHI inference for the D-Fire dataset.

Performance Evaluation Criteria

We will compare all models scientifically using standard evaluation metrics. Falsification criteria mandate strict numeric thresholds (e.g., >30 FPS for Edge Real-Time, <5% False Positive Rate on Visual Mimics).

  • Precision & Recall (mAP@50-95): Standard detection metrics.
  • False Positive Rate (FPR): Critical metric for evaluating YOLO-World vs Co-DETR on environmental noise.
  • Inference Speed (FPS): Must include network latency comparisons (proving the 100% Edge pipeline beats the cloud requirement).
  • Model Size (MB) & FLOPs: Ensuring all models stay under edge constraints.

Final Analysis and Discussion

The final project deliverable will rigorously compare the models across our three experiments:

  • Did RT-DETR successfully break the real-time boundary to beat YOLO11n on drone hardware, or did the CNN maintain its edge?
  • Did YOLO-World's zero-shot vocabulary eliminate distant atmospheric false alarms as effectively as the massive Co-DETR architecture?
  • Did SAHI prevent the degradation of recall for tiny distant targets in 4K imagery compared to naive resizing?

Overall Goal of the Project:

By proving that lightweight visual algorithms can be paired with edge-native zero-shot linguistic reasoning (YOLO-World) and slicing inference techniques (SAHI)—and benchmarking them against the absolute titans of the field like Co-DETR and RT-DETR—we establish a highly robust, 100% edge-deployable blueprint for modern disaster management.
